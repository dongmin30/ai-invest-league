# AI Invest League

사람과 AI 에이전트(Claude, 로컬 LLM, 규칙 기반 봇)가 **가상자금**으로 국내(KR)·해외(US) 주식·ETF 모의투자 리그에서 수익률을 겨루는 웹 앱입니다.
리그는 3일 / 1주 / 1개월 공식 리그와 사용자가 만드는 커스텀 리그가 있으며, 순위는 수익률 → MDD → 거래 횟수 순으로 정해집니다.
국내 리그, 미국 리그 외에 국내·미국 종목을 원화 계좌 하나로 거래하는 **통합 리그**가 있습니다.

> 가상자금으로 하는 교육용 모의투자입니다. 투자 권유가 아닙니다.

모듈 경계, DB 스키마, API 계약은 [`docs/SPEC.md`](docs/SPEC.md)에 정의되어 있습니다.

## 빠른 시작

요구 사항: Node.js 22, npm 10

```bash
npm install
cp .env.example .env      # 선택: 아무 값도 넣지 않아도 실행됩니다
npm run dev               # 서버 http://localhost:8787 + 웹 http://localhost:5173
```

| 명령 | 설명 |
|---|---|
| `npm run dev` | 서버(8787)와 웹(5173, `/api` 프록시)을 함께 실행 |
| `npm run practice` | 연습 모드로 실행 (가상 시세·상시 개장·별도 DB, [아래](#연습-모드-주말야간-테스트) 참고) |
| `npm test` | 서버 테스트 (vitest) |
| `npm run typecheck` | 서버·웹 타입 검사 |
| `npm run build` | 웹을 `web/dist`로 빌드 |
| `npm start` | 서버 실행 (빌드된 `web/dist`를 함께 서빙) |
| `npm run share` | 빌드 후 서버를 띄우고 Cloudflare 임시 주소로 외부 공개 (팀원과 함께 테스트, 회원가입에 입장코드 필요) |

배포처럼 한 프로세스로 띄우려면 `npm run build` 후 `npm start` 하고 http://localhost:8787 에 접속합니다 (서버가 `web/dist`를 서빙).

- **처음 가입한 사용자가 관리자**가 됩니다 (`ADMIN_EMAILS`로 추가 지정 가능). 관리자는 에이전트 상세의 "지금 판단", 리그 화면의 "시세 강제 수집" 버튼을 쓸 수 있습니다.
- 서버가 켜지면 바로 전 종목 시세를 한 번 받고, 이후 `COLLECT_INTERVAL_SEC`(기본 60초)마다 열려 있는 시장만 수집 → 주문 체결 → 순위 갱신을 합니다. 1분마다 리그 시작/종료·공식 리그 생성·에이전트 판단, 10분마다(그리고 장 마감 시) 수익률 스냅샷을 남깁니다.
- 공식 리그(3일/1주/1개월 × 국내·미국·통합, 총 9종류)는 **처음에는 모두 꺼져 있습니다.** 관리자가 리그 화면 위쪽 "공식 리그 자동 운영" 패널에서 켠 종류만 자동으로 만들어져 다음 개장 시각에 시작하고, AI가 참가합니다. 끄면 그 종류의 진행 중 리그는 바로 종료(현재 순위로 마감)되고, 시작 전 리그는 삭제됩니다. 이 기능이 생기기 전 DB로 처음 켜면 모든 종류가 꺼진 상태이므로, 기존 공식 리그도 같은 방식으로 정리됩니다. 바로 시작하는 리그가 필요하면 "커스텀 리그 만들기"에서 즉시 시작을 고르세요.

## 리그 종류

| 리그 | 종목 | 통화·시작 자금 | 수수료 / 매도세 | 공식 리그 판단 주기 · 하루 주문 한도 (3일 / 1주 / 1개월) |
|---|---|---|---|---|
| 국내 (KR) | 국내 105종목 | 원화 · 1,000만원 | 0.015% / 주식 0.20%, ETF 0% | 30분·20회 / 60분·10회 / 180분·5회 |
| 미국 (US) | 미국 163종목 | 달러 · $10,000 | 0.1% / 0% | 30분·20회 / 60분·10회 / 180분·5회 |
| 통합 (ALL) | 국내 + 미국 268종목 | 원화 · 1,000만원 | 종목 시장 기준(국내 0.015%, 미국 0.1%) / 국내 주식 0.20% | 60분·30회 / 120분·15회 / 360분·8회 |

- **통합 리그의 환전**: 미국 종목은 체결 시점의 USD/KRW 환율(Yahoo `KRW=X`, 연습 모드는 가상 환율)로 자동 환전됩니다. **환전 비용은 매수·매도 각 0.1%**(매수 환율 = 중간값 × 1.001, 매도 환율 = 중간값 × 0.999)이고, 수수료는 원화 환산 금액에 붙습니다. 보유 종목 평가는 환율 중간값으로 하므로 환율 변동도 수익률에 반영됩니다. 미국 종목을 한 번 사고팔면 수수료와 환전 비용으로 약 0.4%가 듭니다.
- 환율이 30분 넘게 갱신되지 않으면 미국 종목 주문은 새 환율이 올 때까지 대기합니다(거절되지 않음). 서버가 환율을 한 번도 받지 못했으면 미국 종목 주문이 거절됩니다.
- 통합 리그의 하루는 **08:00 KST**에 바뀝니다: 국내 장(09:00–15:30)과 그날 밤 미국 장(22:30/23:30–다음 날 05:00/06:00 KST)이 같은 하루이고, 하루 주문 한도도 이 단위로 셉니다. 리그 기간도 이 "통합 거래일"로 세므로 보통 마지막 날 미국 장 마감(다음 날 새벽 KST)에 끝납니다. 리그 종료 전에 다시 열리지 않는 시장의 종목은 주문할 수 없습니다.
- 통합 리그에 참가하는 AI는 국내·미국 시장을 모두 거래하는 에이전트여야 합니다.

데이터는 `server/data/app.db`(SQLite)에 저장됩니다. 처음부터 다시 시작하려면 서버를 끄고 `server/data/`를 지우세요.

## 거래 종목 (268개)

| 시장 | 주식 | ETF | 그중 레버리지 / 인버스 |
|---|---|---|---|
| 국내 KR | 74 (KOSPI·KOSDAQ 대형주) | 31 (KODEX·TIGER 지수, 해외지수, 업종·테마, 금·은·원유, 국고채, 달러) | 3 / 5 |
| 미국 US | 103 (대형주) | 60 (지수, 섹터·테마, 채권, 원자재, 배당) | 14 / 14 (+ UVXY 1.5x) |

- 목록은 `server/src/market/symbols.ts`에 있고, 모든 종목은 Yahoo 시세로 실제 조회되는지 확인했습니다. 종목마다 `kind`(주식/ETF), `leverage`(1, 2, 3, -1, -2, -3), 기초 종목(`underlying`, 예: SQQQ → QQQ, KODEX 레버리지 → KODEX 200), 분류가 붙습니다.
- **레버리지·인버스 ETF**는 기초지수 *하루* 수익률의 배수를 추종합니다. 매일 재조정되므로 오래 들고 있으면 변동성 때문에 가치가 줄어드는 경향이 있습니다(주문 화면에 경고 표시). 신용·공매도는 여전히 불가하며, 이런 ETF를 현금으로 사는 것만 가능합니다.
- **세금**: 국내 주식 매도 시 거래세 0.20%, **국내 ETF 매도는 증권거래세 면제(0%)**, 미국은 0%. 수수료는 그대로입니다.
- **AI 에이전트**에는 판단마다 최대 40종목만 보여 줍니다 (보유·대기 주문 종목, 대표 지수 ETF, 등락률·거래대금 상위; 레버리지·인버스는 최대 6개). 통합 리그에서는 지금 열려 있는 시장에 남은 자리의 60%를 줍니다. 주문 자체는 리그 시장의 전체 종목에 대해 가능합니다. `기준선 봇`은 주식만(통합 리그는 국내 5 + 미국 5종목, 각 시장이 열렸을 때), `모멘텀 봇`은 주식과 1배 ETF만 삽니다.
- 시세는 Yahoo spark 묶음 요청(20종목씩)으로 받아 한 번 갱신에 미국 9회·국내 6회 요청이면 됩니다. 빠진 종목만 종목별 차트 요청으로 다시 받습니다.

## 키 없이 바로 데모하기

키가 하나도 없어도 동작합니다.

- 시세: 기본값 `PRICE_PROVIDER=yahoo`는 키가 필요 없는 Yahoo Finance 차트 JSON을 사용합니다 (지연 시세일 수 있음).
- 에이전트: 규칙 기반 `기준선 봇`, `모멘텀 봇`은 항상 활성화됩니다.

주말이나 장 마감 후에 시연하려면 오프라인 시세와 상시 개장 모드를 켜세요.

```env
PRICE_PROVIDER=sim
SIM_ALWAYS_OPEN=true
```

## 연습 모드 (주말·야간 테스트)

장이 닫혀 있을 때 매수·매도를 바로 시험해 보려면 연습 모드를 쓰세요. `.env`와 실제 DB는 건드리지 않습니다.

1. 실행 중인 `npm run dev`를 먼저 끕니다 (같은 포트 8787/5173을 씁니다).
2. `npm run practice` 를 실행하고 http://localhost:5173 에 접속합니다. 화면 상단에 `연습 모드 · 가상 시세` 표시가 나옵니다.
3. 가입한 뒤(연습 DB의 첫 가입자가 관리자) 리그 화면의 "공식 리그 자동 운영"에서 원하는 공식 리그를 켜면 바로 시작되고, "커스텀 리그 만들기"의 즉시 시작도 쓸 수 있습니다. 참가해서 주문하면 됩니다. 시세와 가상 환율은 10초마다 갱신·체결됩니다.

- 시세는 진짜가 아닌 시뮬레이션(랜덤워크)입니다. 연습 DB에 저장된 마지막 시세에서 이어지고, 연습 DB가 비어 있는 처음에는 시작할 때 Yahoo에서 최신 실제 가격을 한 번 받아와 거기서 시작합니다(실패하면 내장 기준가, 2026-10-30 종가). 레버리지·인버스 ETF는 기초 종목 움직임의 배수로 움직입니다(예: SQQQ는 QQQ의 −3배).
- 데이터는 `server/data/practice/`에 따로 저장됩니다. 계정도 따로이니 연습 모드에서 새로 가입하세요. 서버를 끈 뒤 이 폴더는 언제든 지워도 됩니다.
- 비용을 막기 위해 연습 모드에서는 Claude 에이전트가 꺼져 있습니다. 켜는 방법과 대략적인 비용은 `.env.practice` 주석을 보세요. 그 밖의 설정(Ollama 등)은 `.env` 값을 그대로 씁니다.
- 설정은 `.env.practice`에 있으며, 서버가 `.env`를 읽은 뒤 `ENV_OVERLAY` 로 지정한 이 파일의 값으로 덮어씁니다.

## 선택: API 키 받기

### Claude 에이전트 (`ANTHROPIC_API_KEY`)

Max 플랜에 포함된 월간 API 크레딧으로 Claude 에이전트를 돌릴 수 있습니다.

1. claude.ai → **Settings > Billing** 에서 Claude Console 조직을 연결합니다 (월간 API 크레딧이 그 조직에 적립됩니다).
2. [Claude Console](https://console.anthropic.com) → **API Keys** 에서 키를 만듭니다.
3. `.env`에 `ANTHROPIC_API_KEY=sk-ant-...` 를 넣고 서버를 재시작하면 `Claude 트레이더`가 활성화됩니다.

`CLAUDE_MODEL`(기본 `claude-opus-5-5`)과 `CLAUDE_EFFORT`(기본 `low`)로 모델과 추론 강도를 조절합니다. 크레딧을 아끼려면 리그의 의사결정 주기를 길게 두세요.
claude.ai 구독 로그인 토큰(OAuth)은 서버에 넣지 마세요. 반드시 Console API 키를 사용합니다.

### 한국투자증권 Open API (`KIS_APP_KEY`, `KIS_APP_SECRET`) — 선택

Yahoo 대신 증권사 공식 시세를 쓰고 싶을 때만 필요합니다.

1. 한국투자증권 계좌를 개설하고 [KIS Developers](https://apiportal.koreainvestment.com)에서 Open API 서비스를 신청합니다.
2. 실전투자 앱키(App Key)와 앱시크릿(App Secret)을 발급받습니다 (시세 조회 전용으로만 사용합니다).
3. `.env`에 `PRICE_PROVIDER=kis`, `KIS_APP_KEY`, `KIS_APP_SECRET`을 설정합니다.

KIS 연동 코드는 키가 제공되기 전까지 실제 계정으로 검증되지 않았습니다.

### 로컬 LLM (Ollama) — 선택

1. [Ollama](https://ollama.com)를 설치하고 모델을 받습니다: `ollama pull qwen3:8b`
2. `.env`에 `OLLAMA_BASE_URL=http://localhost:11434` (필요하면 `OLLAMA_MODEL`)을 설정합니다.
3. 서버 부팅 시 Ollama에 접속되면 `로컬 LLM 트레이더`가 활성화됩니다.

## 시세 제공자 (`PRICE_PROVIDER`)

| 값 | 키 | 설명 |
|---|---|---|
| `yahoo` (기본) | 불필요 | Yahoo Finance 차트 JSON. 지연될 수 있으며 비공식 엔드포인트입니다. |
| `kis` | KIS 앱키 필요 | 한국투자증권 Open API 시세 |
| `sim` | 불필요 | 오프라인 랜덤워크. `SIM_ALWAYS_OPEN=true`와 함께 데모용 |

포털 사이트 HTML 스크래핑(예: 네이버 금융)은 사용하지 않습니다.
